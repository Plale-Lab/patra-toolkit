# Model Card Schema Descriptions
### Model Card Documentation

This documentation details the fields for configuring a `ModelCard`. Only `name` is required — every
other field is optional. `uuid` is assigned by the Patra server upon submission (or may be pre-supplied
to request a specific identifier). `bias_analysis`/`xai_analysis` are populated via `populate_bias()`/
`populate_xai()` and are kept for local use/inspection only — the Patra server does not persist them.

| Field Name           | Type              | Description                                                               | Constraints/Example Values                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|----------------------|-------------------|---------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `name`               | `str`             | **Required**. The name of the model card.                                 | Example: `"Model Card for Sentiment Analysis"`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Optional Fields**  |       |                                                                       |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `version`            | `str`             | The version of the model card.                              | Example: `"1.0.0"`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `short_description`  | `str`             | A brief description of the model card.                      | Example: `"This model detects sentiment in text data."`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `full_description`   | `str`             | A comprehensive description of the model card.              | Example: `"This model performs sentiment analysis using NLP techniques and is trained on customer feedback data."`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `keywords`           | `str`             | Keywords associated with the model card.                    | Example: `"sentiment analysis, NLP, text classification"`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `author`             | `str`             | Author or creator of the model card.                        | Example: `"Jane Doe"`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `input_type`         | `str`             | Type of input data accepted by the model.                   | Example: `"text, image, tabular"`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `category`           | `str`             | Model category from predefined types.                       | Enum: `"classification", "regression", "clustering", "anomaly detection", "dimensionality reduction", "reinforcement learning", "natural language processing", "computer vision", "recommendation systems", "time series forecasting", "graph learning", "graph neural networks", "generative modeling", "transfer learning", "self-supervised learning", "semi-supervised learning", "unsupervised learning", "causal inference", "multi-task learning", "metric learning", "density estimation", "multi-label classification", "ranking", "structured prediction", "neural architecture search", "sequence modeling", "embedding learning", "other"` |
| `input_data`         | `str`             | URL or DOI for the input data.                              | Must be a valid URL, DOI, or empty string.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `output_data`        | `str`             | URL or DOI for the output data.                             | Must be a valid URL, DOI, or empty string.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `foundational_model` | `str`             | Foundational model ID or URL if applicable.                 | Example: `"https://huggingface.co/docs/transformers/en/model_doc/flan-t5"`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `documentation`      | `str`             | URL link to documentation for the model.                    | Example: `"https://docs.example.com/modeldocs.md"`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `training_datasheet_uuid` | `str`       | `uuid` of a `Datasheet` used to train the model.            | Must reference an existing datasheet on the server.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `is_private`         | `bool`            | Whether the model card is private.                          | Default: `False`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `is_gated`           | `bool`            | Whether the model card is gated.                             | Default: `False`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `uuid`               | `str`             | Unique identifier for the model card.                        | Assigned by the server upon submission, or pre-supplied by the caller.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |



### AI Model Documentation

This documentation details the fields for configuring an `AIModel`, representing the essential metadata
for the underlying AI model within a `ModelCard`. Only `name` is required.

| Field Name           | Type              | Description                                                                                                          | Constraints/Example Values                                                                                    |
|----------------------|-------------------|----------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------|
| `name`               | `str`             | **Required**. The name of the AI model.                                                                              | Example: `"Sentiment Analysis Model"`.                                                                        |
| **Optional Fields**  |                   |                                                                                                                      |                                                                                                               |
| `version`            | `str`             | The version of the AI model.                                                                           | Example: `"1.0.0"`.                                                                                           |
| `description`        | `str`             | A description of the AI model's functionality and purpose.                                             | Example: `"This model is trained to detect sentiment in customer feedback."`                                  |
| `owner`              | `str`             | The individual or organization that owns the model.                                                    | Example: `"Jane Doe"`.                                                                                        |
| `location`           | `str`             | Downloadable URL of the model.                                                                         | Example: `"https://modelrepository.com/model/123"`.                                                           |
| `license`            | `str`             | License type for the model usage.                                                                      | Example: `"Apache-2.0"`.                                                                                      |
| `framework`          | `str`             | Framework used for developing the model.                                                               | Enum: `"sklearn", "tensorflow", "pytorch", "other"`.                                                          |
| `model_type`         | `str`             | Type of AI model structure.                                                                            | Enum: `"cnn", "decision_tree", "dnn", "rnn", "svm", "kmeans", "llm", "random_forest", "lstm", "gnn", "other"` |
| `test_accuracy`      | `float`           | Accuracy of the model on test data.                                                                    | Example: `0.89`.                                                                                              |
| `model_structure`    | `object`          | Structure of the model in JSON format.                                                                 | Example: `{"layers": [{"type": "Conv2D", "filters": 32}]}`.                                                   |
| `model_metrics`      | `dict`            | Dictionary of performance metrics for the model. Use `ai_model.add_metric(key, value)` to add metrics. | Example: `ai_model.add_metric("Test loss", loss)`                                                                                                     |
| `inference_labels`   | `list[str]`       | Inference labels for the AI model.                                                                     | Example: `["cat", "dog"]`                                                                                     |


You can validate the model card contents against this schema to ensure that all required fields are present using the following command:
```python
mc.validate()
```

## Datasheet Documentation

A `Datasheet` documents a dataset using DataCite-style metadata. No fields are required to construct
one, but `submit()`/`validate()` require at least one `title` and one `creator` (add via `add_title()`/
`add_creator()`).

| Field Name             | Type   | Description                                                        |
|------------------------|--------|----------------------------------------------------------------------------|
| `uuid`                 | `str`  | Unique identifier, assigned by the server upon submission or pre-supplied. |
| `publication_year`     | `int`  | Year the dataset was published.                                            |
| `resource_type`        | `str`  | Free-text resource type (e.g., `"Dataset"`).                               |
| `resource_type_general`| `str`  | DataCite general resource type.                                            |
| `size`                 | `str`  | Size of the dataset (e.g., `"1.2 GB"`).                                    |
| `format`               | `str`  | Format of the dataset (e.g., `"CSV"`).                                     |
| `version`              | `str`  | Version of the dataset.                                                    |
| `is_private`           | `bool` | Whether the datasheet is private. Default: `False`.                        |
| `publisher`            | `DatasheetPublisher`             | Set via `ds.set_publisher(name, ...)`.                   |
| `creators`             | `list[DatasheetCreator]`         | Add via `ds.add_creator(creator_name, ...)`.              |
| `titles`               | `list[DatasheetTitle]`           | Add via `ds.add_title(title, ...)`.                       |
| `subjects`             | `list[DatasheetSubject]`         | Add via `ds.add_subject(subject, ...)`.                   |
| `contributors`         | `list[DatasheetContributor]`     | Append `DatasheetContributor(...)` directly.               |
| `dates`                | `list[DatasheetDate]`            | Add via `ds.add_date(date, date_type, ...)`.               |
| `alternate_identifiers`| `list[DatasheetAlternateIdentifier]` | Append `DatasheetAlternateIdentifier(...)` directly.  |
| `related_identifiers`  | `list[DatasheetRelatedIdentifier]`   | Append `DatasheetRelatedIdentifier(...)` directly.    |
| `rights_list`          | `list[DatasheetRights]`          | Append `DatasheetRights(...)` directly.                    |
| `descriptions`         | `list[DatasheetDescription]`     | Add via `ds.add_description(description, description_type, ...)`. |
| `geo_locations`        | `list[DatasheetGeoLocation]`     | Append `DatasheetGeoLocation(...)` directly.               |
| `funding_references`   | `list[DatasheetFundingReference]`| Add via `ds.add_funding_reference(funder_name, ...)`.      |

```python
from patra_toolkit import Datasheet

ds = Datasheet(publication_year=2025, version="1.0")
ds.add_title("UCI Adult Dataset")
ds.add_creator("Becker, B.")
ds.validate()
ds.submit(patra_server_url=<patra_server_url>)
```
